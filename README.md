# Field Sales Route Plan & GPS Tracking

Clean stable Odoo 16 Community build.

## Included
- Market routes and multiple salespeople per route
- Daily route planning and approval workflow
- Mobile My Field Work page
- GPS check-in/check-out with inline place resolution
- POS settlement summary tracking
- Delivery tracking and signatures
- Client map / heat map
- Smart reminders, AI assistant, merchandising audits and attendance tracking
- Executive and manager dashboards
- Field Sales User / Field Sales Supervisor access control

## Removed
- Offline sync
- Collections
- Geofence restrictions
- PWA install feature
- Board addon dependency


Version 13.24.0: Restricted management/control menus to Field Sales Manager: license management, team hierarchy, programs/catalogues, visit purposes, unproductive call reasons, executive dashboard, manager dashboard, field device status, merchandising audits, sales gamification, AI chat assistant, and smart reminders.


Version 13.27.0: Sales Persons and Supervisors can read/use Field Visit Purpose values on route plans and visits; only Sales Managers manage the catalogue.
